# Portafolio de Redes y Telecomunicaciones

Portafolio técnico enfocado en **redes, telecomunicaciones e infraestructura TI**, con proyectos académicos y prácticos orientados al diseño, configuración, seguridad y gestión de redes.

## Áreas de interés

- Networking y Telecomunicaciones
- Routing y Switching
- Infraestructura de redes
- Seguridad de redes
- Redes LAN empresariales
- Software-Defined Networking (SDN)
- Redes programables
- IoT y sistemas embebidos

## Tecnologías

**Networking:** Cisco IOS, Cisco Packet Tracer, IPv4, VLAN, 802.1Q, Routing, Switching, DHCP, NAT, ACL, SSH, STP.

**SDN y redes programables:** Ryu, OpenFlow, Mininet, Python.

**Desarrollo:** Python, FastAPI, JavaScript, Git y GitHub.

## Proyectos

### 01. Arquitectura de seguridad perimetral empresarial
Diseño e implementación de una arquitectura de red empresarial con segmentación, seguridad perimetral, DMZ, NAT, ACL y routing.

### 02. Infraestructura LAN empresarial
Implementación de una red LAN segmentada mediante VLAN, trunking, DHCP, inter-VLAN routing y mecanismos de seguridad de capa 2.

### 03. Plataforma SDN
Desarrollo de una plataforma orientada a la gestión y visualización de redes definidas por software mediante tecnologías de control y virtualización de redes.
